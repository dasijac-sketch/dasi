# ניהול תקציב משפחתי – אתר למאמנת

אתר שבו את מוסיפה זוגות, כל זוג מקבל **קישור אישי** ונכנס ממנו ישירות מהטלפון, **בלי חשבון ובלי סיסמה**. את נכנסת למסך ניהול עם סיסמה.

## איך זה עובד

**זוגות** (`/c/<קוד אישי>`)
- שלב 1: ממלאים מאזן חודשי, חסכונות, הלוואות, ביטוחים ויעדים.
- שלב 2 (את פותחת אותו): רואים את התקציב שבנית להם (לצפייה בלבד) ומדווחים הכנסות והוצאות בפועל כל חודש, עם סימון חריגות.
- רואים הודעות ואתגרים ממך.

**מנהלת** (`/admin`)
- הוספת זוג חדש וקבלת הודעה מוכנה עם הקישור האישי (העתקה או שליחה בוואטסאפ).
- רשימת כל הזוגות וסטטוס: ממתינים למאזן, לא דיווחו החודש, חריגות.
- לכל זוג: סקירה, צפייה במאזן ובמעקב החודשי (לקריאה בלבד), **בניית התקציב** (העתקה מהמאזן ועריכה), הערות פרטיות, משימות לפגישה, שליחת הודעות ואתגרים, מעבר בין שלבים, קישור חדש, מחיקה.
- הורדת גיבוי של כל הנתונים.

## העלאה לאינטרנט (מומלץ: Render)

1. **GitHub:** פתחי חשבון חינם ב-github.com, צרי מאגר חדש (Repository) **פרטי**, והעלי אליו את כל הקבצים מהתיקייה הזו (Add file ← Upload files). אל תעלי תיקיית `node_modules` או `data` אם קיימות.
2. **Render:** פתחי חשבון ב-render.com ← New ← **Blueprint** ← בחרי את המאגר. הקובץ `render.yaml` מגדיר הכול אוטומטית.
3. כשתתבקשי, הזיני ערך ל-**ADMIN_PASSWORD**. זו הסיסמה שלך למסך הניהול, לפחות 8 תווים, מומלץ ארוכה וייחודית.
4. אחרי כמה דקות תקבלי כתובת כמו `https://budget-coach.onrender.com` (אפשר לחבר גם כתובת משלך). 
5. כניסה: `הכתובת שלך/admin`.

> **חשוב:** האתר שומר נתונים בקובץ בדיסק. ב-Render צריך תוכנית בתשלום עם דיסק (כמו ב-`render.yaml`). בתוכנית החינמית אין דיסק קבוע והנתונים יימחקו. את המחיר העדכני בדקי באתר Render. אפשר להשתמש גם בשירותים דומים (Railway, Fly.io) כל עוד יש דיסק קבוע, ולהגדיר את התיקייה שלו במשתנה `DATA_DIR`.

אם יש לך מתכנת או מישהו טכני, ההעלאה לוקחת לו כרבע שעה.

## הרצה במחשב לבדיקה

```
npm install
ADMIN_PASSWORD=סיסמה-ארוכה SESSION_SECRET=מחרוזת-אקראית-ארוכה npm start
```
ואז לפתוח `http://localhost:3000/admin`.

## אבטחה ופרטיות

- **הקישור האישי הוא המפתח.** כל מי שמחזיק בו רואה את נתוני הזוג, ולכן לשלוח אותו רק לזוג עצמו. אם הקישור נחשף, לחצי "קישור חדש" בלשונית "ניהול" והישן יפסיק לעבוד.
- הקודים ארוכים ואקראיים ואי אפשר לנחש אותם. יש הגבלה על ניסיונות ניחוש וניסיונות כניסה למנהלת.
- בעצם הפרסום ב-Render החיבור מוצפן (HTTPS).
- הזוג **לא יכול** לשנות את התקציב שקבעת, והשרת חוסם זאת גם אם מנסים לעקוף את הממשק.
- הדפים לא נחשפים למנועי חיפוש.
- **גיבוי:** מומלץ ללחוץ מדי פעם על "הורדת גיבוי" במסך הניהול ולשמור את הקובץ.
- מדובר במידע פיננסי אישי. כדאי להתייעץ לגבי דרישות חוק הגנת הפרטיות, ולהוסיף לזוגות הסבר קצר על השימוש במידע.

## מה בפנים

| קובץ | תפקיד |
|---|---|
| `server.js` | השרת, מסד הנתונים (SQLite), כניסת מנהלת וקישורים אישיים |
| `public/lib.js` | הקטגוריות, החישובים והתצוגות המשותפות |
| `public/couple.js` | האפליקציה של הזוג |
| `public/admin.js` | מסך הניהול |
| `public/style.css` | עיצוב |
| `render.yaml` | הגדרת העלאה ל-Render |

**שינוי קטגוריות וסעיפים:** בראש הקובץ `public/lib.js` מופיעה הרשימה `D` עם כל הקבוצות והסעיפים. אפשר לערוך אותה ישירות.
